СТАРИНА / ABIOMA v0.3

Что изменено:
— экран разговора теперь является ОСНОВНЫМ экраном;
— используется фирменный знак ABIOMA из присланного изображения;
— добавлен PWA-манифест и иконки для экрана iPhone;
— текстовый чат подключён к серверному маршруту /api/chat;
— сервер готов работать с OpenAI Responses API;
— API-ключ хранится только на сервере, а не в браузере.

Запуск на компьютере/сервере:
1. Установите Node.js 18+.
2. В терминале:
   export OPENAI_API_KEY="ваш_ключ"
   node server.js
3. Откройте http://localhost:3000

Важно: не вставляйте API-ключ прямо в HTML/JavaScript браузера.
Для iPhone сайт нужно разместить по HTTPS, открыть в Safari,
затем Поделиться → На экран «Домой».
