# Публикация на iPhone

Чтобы «Старина» стал отдельной иконкой на iPhone, проект сначала нужно разместить на HTTPS-хостинге.

Минимальная схема:
- загрузить папку проекта на Node.js-хостинг;
- команда сборки: npm install
- команда запуска: npm start
- добавить секрет OPENAI_API_KEY в переменные окружения;
- открыть выданный HTTPS-адрес в Safari;
- Поделиться → На экран Домой → Добавить.

После этого приложение запускается почти как отдельное приложение без обычной адресной строки Safari.
