# Старина / ABIOMA v0.4

В этой версии готовы четыре слоя:

1. ТЕКСТ
   Поле ввода подключено к OpenAI Responses API через сервер /api/chat.

2. ГОЛОС
   Кнопка микрофона записывает речь → /api/transcribe → gpt-4o-transcribe.
   Ответ Старина озвучивает через /api/speak → gpt-4o-mini-tts, голос cedar.

3. ПАМЯТЬ
   Для каждого браузера создаётся sessionId. Последние реплики сохраняются
   на сервере в memory.json и возвращаются модели в следующих запросах.
   Это простая память для прототипа; для продакшена её лучше перенести в БД.

4. IPHONE
   Есть PWA manifest, apple-touch-icon и standalone-режим.
   После публикации по HTTPS:
   Safari → Поделиться → На экран Домой → Добавить.

## Запуск
Нужны Node.js 18+ и отдельный OpenAI API key.

npm install
export OPENAI_API_KEY="ВАШ_КЛЮЧ"
npm start

Открыть: http://localhost:3000

ВАЖНО
API-ключ нельзя вставлять в index.html и нельзя публиковать в GitHub.
Он должен быть секретной переменной окружения на сервере.
